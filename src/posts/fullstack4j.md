In my note on [Fullstack](/fullstack/), I suggested that a team skilled in Java might not need a JavaScript SPA at all. A mature server-side framework like Apache Wicket keeps the team in one language and lets everyone work on user-facing vertical slices instead of splitting into frontend and backend members.

Since then, I have been building the tools to make that easy: [Wicket Oat]({{ projects[0].url }}), the [Wicket Spring Boot Starter]({{ projects[1].url }}) and [fullstack4j start]({{ projects[2].url }}).

Now it all comes together in [fullstack4j]({{ site.fullstack4j }}), an offering of the [allwerker cooperative]({{ site.allwerker }}) that I lead. Together with my colleagues, I help companies set up, staff and coach teams of two or three people who own whole features in plain Java, from the database to the button: Spring Boot, Apache Wicket, Spring Modulith and MongoDB, with AI agents taking the routine work off their hands. We slice the work with Event Modeling and build it in Shape Up-style cycles.
